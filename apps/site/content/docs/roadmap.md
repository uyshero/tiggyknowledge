# 后续规划

当前桌面版已经可以在本机管理知识库、检索、Wiki，以及向智能体提供只读接口。下面这些方向还在规划中，尚未发布。

本地优先不会被企业能力取代。企业版是同一种产品的另一种部署形态：团队可以共享知识库，个人资料仍然可以留在本地。

## 企业版与共享知识库

面向团队提供可共享的知识库，而不是把个人本机库直接搬到公网。

- 团队共用一套知识库，按范围授权访问。
- 云端形态与本地形态共用同一套核心能力，而不是另做一套产品。
- 个人库与团队库可以并存；两端不做后台自动同步。
- 如需迁移，走导出 / 导入，而不是实时双向同步。

第一阶段不会做复杂组织架构、在线协同编辑或多端冲突合并。

## 更多格式解析

导入能力会按插件继续扩展。当前已支持 Markdown、纯文本、PDF 和网址页面。后续会增加更多常见资料格式的解析与预览，例如办公文档和其他常见文本载体，让资料可以进入同一套检索和 Wiki。

解析、预览和索引仍然拆成插件，新增一种格式不应改动知识库内核。

## 创作：笔记与录音

知识库不只收已有文件，也会加强在库内直接创作。

- 记录笔记：当前已可分栏编辑 Markdown 条目，保存后留下版本并可回滚。后续会继续补录音等创作入口。
- 录音：支持录制或导入语音，转成可检索的文字条目，并保留来源。
- 其他轻量创作入口会按同样方式进入知识库，而不是散落在应用外。

## 智能修改文件

在已有资料上做有依据的改写，而不是只生成新的 Wiki。

- 按一条指令修订笔记、文档或导入后的正文。
- 改动可预览、可确认，并留下版本，避免直接覆盖无法回退。
- 改写应引用库内内容；需要落到原文件时，走明确的写入动作，而不是静默改盘。

智能体接入目前仍是只读。写入类能力（创建笔记、修改文件、打标签、导入）会作为后续扩展，不会先绑到某一个 Agent 框架。

## 不会先做的事

- 本地与云端实时同步
- 后台自动同步
- 多端冲突自动合并
- 完整企业 SaaS 组织架构
- 多人同时在线协同编辑

# 快速开始

小虎AI知识库是本地优先的桌面知识库。资料保存在你的电脑上，本机服务默认监听 `http://127.0.0.1:3210`。

## 1. 安装桌面版

前往 [下载页](/download) 获取最新安装包：

- macOS：`.dmg`（Apple Silicon 或 Intel）
- Windows：NSIS 安装包（x64）

当前安装包尚未代码签名。macOS 可能提示无法验证开发者，Windows 可能出现 SmartScreen 提示。请从 [GitHub Releases](https://github.com/uyshero/tiggyknowledge/releases) 下载，不要使用来路不明的安装包。

## 2. 打开应用

启动后，Electron 会拉起本机 Host 服务并打开产品界面。侧栏品牌名为「小虎AI知识库」。

- 同一时间只运行一个实例；再次打开会把已有窗口带到前台。
- macOS 关闭窗口后应用仍可从程序坞恢复，不会重启 Host。

## 3. 创建知识库

1. 打开「知识库」。
2. 新建一个知识库，填写名称和简介。
3. 进入该知识库，准备导入文档。

## 4. 导入文档

打开「上传」，选择知识库后导入文件。当前支持：

- Markdown（`.md` / `.markdown`）
- 纯文本（`.txt`）
- PDF（`.pdf`，单个文件不超过 200 MB；超过 5000 页仍可导入，检索和 Wiki 使用前 5000 页文本，预览可翻阅全文）
- 网址快捷方式（`.url` / `.webloc`）

导入时可以顺便打标签。相同内容不会在同一知识库里重复入库。

也可以在知识库内直接新建 Markdown 条目，或添加一个网址。笔记编辑是分栏预览，保存后可回看版本并回滚。网址条目会保存链接，预览和解析时实时加载页面，不把整页存成本地快照。

## 5. 检索与阅读

- 用「搜索」按关键词查找片段，再打开对应条目。
- 在条目详情中预览正文；PDF 可在应用内阅读。
- 「全部标签」和「收藏」用于整理常用资料。

## 6. 可选：Wiki 与智能体

如果要让 AI 把知识库整理成带引用的 Wiki：

1. 打开「设置 → AI 模型」，配置提供方、模型和 API Key。
2. 回到「Wiki」，生成或更新词条。

如果要把知识库提供给外部智能体：

1. 打开「设置 → 智能体集成」。
2. 生成访问 Key，并选定该 Key 可访问的知识库范围。
3. 按 [智能体接入](/docs/agent-api) 调用只读接口。

默认接入地址是 `http://127.0.0.1:3210`。

# 产品功能

小虎AI知识库把本地资料变成可检索、可引用、可交给智能体使用的知识。以下能力都在当前桌面版中可用。

## 知识库与文档

可以创建多个知识库，分别存放不同主题的资料。每个知识库包含文档列表、导入记录和条目详情。

- 导入 Markdown、纯文本和 PDF。
- 保存网址，预览时实时加载页面。
- 直接新建 Markdown 知识条目，分栏预览，保存后可回看版本并回滚。
- 在条目中预览正文，并为 PDF 保留应用内阅读。
- 用标签和收藏整理常用文档。

## 搜索

搜索页提供关键词检索，并可按知识库、收藏范围筛选。若已配置语义能力，还可以使用语义或混合检索。

搜索结果给出标题、摘要片段和来源位置。先用搜索拿线索，再打开条目阅读全文。

## Wiki

配置本地或远程大模型后，可以从知识库生成结构化 Wiki：

- 分析现有文档，提出新增、更新或归档计划。
- 词条带来源引用，可追溯到原始文档。
- 支持版本、草稿恢复与治理检查。

Wiki 依赖「设置 → AI 模型」中的提供方和 API Key。未配置模型时不会调用外部服务。

## 知识库对话

在知识库中可以直接提问。应用会检索相关文档，并可按当前文章、指定文章或整个知识库进行总结。回答应基于库内资料，而不是凭空生成。

## 智能体只读接口

本机 Host 对外提供 `/api/tiggyknowledge/*` 只读接口，供外部智能体列出知识库、搜索、读取正文和获取 OKF 映射。

- 使用 Bearer 访问 Key，Key 在「设置 → 智能体集成」中生成。
- 每个 Key 可以限制到全部知识库或指定知识库。
- 接口不绑定某一个智能体框架；deepseek-harness 只是参考接入方。

详见 [智能体接入](/docs/agent-api)。

## 自定义插件

产品按插件组装。内置能力用户不能关。第三方插件按同一套 Cordis 契约编写，装上之后可以关闭。

开发流程、命名、HTTP 与 Client 扩展点见 [第三方插件](/docs/plugins)。

设置 → 插件列表可以查看当前 Host / Client 运行状态。后续规划中的企业能力、更多格式和创作功能，也会继续以插件形式加入。
